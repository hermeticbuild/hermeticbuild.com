# ABOUT HERMETIC BUILD

We build open-source infrastructure for building and testing software. For developers and agents.

Hermetic toolchains. Cross-compilation. Remote execution.
Designed together, from the compiler to the build system.

Our users include:

  • * linux.bzl — Build and customize Linux kernels from source.
